# Paradise Nursery Shopping Application

Paradise Nursery is a responsive shopping cart web application for an online plant shop. The project was built using React, Vite, Redux Toolkit, React Redux, and React Router.

## Features

- Paradise Nursery landing page
- Company information section
- Product listing with three plant categories
- Six unique plants in each category
- Plant images, names, and prices
- Add to Cart functionality
- Disabled button after a product is added
- Dynamic shopping cart item counter
- Increase and decrease item quantities
- Remove products from the shopping cart
- Individual plant totals and overall cart total
- Continue Shopping navigation
- Checkout placeholder message

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Redux
- React Router DOM
- CSS
